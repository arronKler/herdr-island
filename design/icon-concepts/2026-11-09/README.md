# Herdr Island 图标方案 · 2026-11-09

本轮提供 10 个独立的应用图标概念，围绕当前应用的刘海、水滴、任务派发和多 agent 状态展开。使用内置 `image_gen` 逐个生成；完整提示词保存在 [prompts.json](prompts.json)。

- [打开对比页](index.html)：支持浅色 / 深色背景，附 16 / 32 / 64 px 缩略预览；点击图标打开原始 PNG。
- [浅色总览](overview-light.png) / [深色总览](overview-dark.png)：带编号的完整对照图。
- 10 张原始图标均为 1254 × 1254 PNG，保留生成的透明通道，全部保存在本目录；尺寸与文件哈希见 [assets.json](assets.json)。
- 已选定 **10「负形之岛」**，重绘为 [SVG 正式源文件](../../../Sources/IslandApp/Resources/Brand/HerdrIsland.svg)，并接入应用包、菜单栏、任务台和设置页。本目录继续保留原始 10 版概念图用于回看；实际应用使用由 SVG 生成的干净矢量 / ICNS 资源。

| 编号 | 方案 | 设计意图 | 取舍 |
| --- | --- | --- | --- |
| 01 | [刘海水滴](01-notch-drop.png) | 刘海下悬挂一滴水，直接对应产品的标志性交互 | 产品关联最强；需注意细颈在极小尺寸下的表现 |
| 02 | [液态 H](02-liquid-h.png) | Herdr 首字母与液态连接合成一个品牌标志 | 轮廓简洁，适合长期品牌化；功能含义较抽象 |
| 03 | [协同轨道](03-agent-orbit.png) | 三个 agent 状态节点围绕任务核心 | 协同含义明确；元素较多，需简化菜单栏版 |
| 04 | [浮岛群](04-archipelago.png) | 三座独立小岛组成一个协同工作区 | 温和、有 Island 意象；开发工具属性较弱 |
| 05 | [终端之滴](05-terminal-drop.png) | 水滴里嵌入终端提示符 | 工具定位直接，色彩醒目；终端符号较常见 |
| 06 | [窗口牵引](06-window-tether.png) | 窗口通过短连接牵引水滴 | 对应锁定窗口功能；细节需要为小尺寸简化 |
| 07 | [涟漪启动](07-ripple-launch.png) | 水滴落下，涟漪成为新任务的起点 | 动作感强，易衍生动画；需避免被理解为天气应用 |
| 08 | [群航](08-agent-flock.png) | 三个同向单元代表多个 agent 并行推进 | 轻快清楚；与刘海和水滴的直接关联较弱 |
| 09 | [任务叠层](09-task-deck.png) | 多个任务归拢到同一个入口 | 强调任务管理；与通用效率工具的区分度较低 |
| 10 | [负形之岛](10-negative-island.png) | 刘海胶囊中的水滴负形构成简洁标记 | 适合继续发展单色标志；材质感较克制 |

## 检视范围

生成后检查全部图像的内容、尺寸与透明通道，并在对比页查看小尺寸表现。浏览器确认 10 个方案与 40 张主图 / 缩略图全部加载，深浅背景切换正常，1600px 和 390px 视口均无横向溢出。部分浅底方案的透明外沿存在生成杂边，当前保留原始生成结果；选定方向后需要清理边缘、校准小尺寸轮廓，再制作应用图标和菜单栏模板图。

概念设计依据为 `README.md`、`Sources/IslandApp/Theme.swift` 和 `Resources/Info.plist`。后续选定版本的接入说明见项目 README。
