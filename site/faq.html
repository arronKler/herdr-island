01 / BasicsWhat is it, and how does it relate to Herdr?

What is Herdr Island, and how does it relate to Herdr?

Island is the macOS graphical front end for Herdr. Herdr remains the executor: it creates workspaces, starts agents, submits messages, and runs terminals. Island puts status, the deck, the terminal, and dispatch beside the notch. It does not replace Herdr or talk to Claude Code / Codex by itself.

That means Island can cover exactly the agents that Herdr recognizes and starts.

Do I need to install Herdr first?

Yes. Island requires Herdr 0.9.5; the interactive terminal in the detail view speaks the single-pane protocol 22. The default binary path is ~/.local/bin/herdr and the socket is ~/.config/herdr/herdr.sock. You can override them with HERDR_SOCKET_PATH or HERDR_SOCKET.

Settings → Environment shows the executable and socket Island actually found. Restart Island after moving Herdr to refresh them.

Which agents are supported?

Every agent Herdr recognizes appears in the deck. New tasks can start Claude, Codex, Cursor, Pi, Gemini, Copilot, OpenCode, Cline, Amp, Grok, Qwen, or Kimi — 12 kinds in total.

Agents differ in how they accept a first task and how they handle blocked prompts. A single-line first task for Claude or Cursor can be passed natively as a launch argument. Codex and multi-line tasks first wait for a real empty input box. Cursor's workspace-trust dialog and Codex's usage/model picker are always yours to handle.

Does Island auto-approve blocked agents?

No. Island never sends y, Enter, or any confirmation key. Automatic delivery uses herdr agent prompt, which refuses a blocked agent.

You can read, choose, and answer in the detail terminal, or click "Open in Herdr" and handle it there. The settings page states the same rule: blocked is never auto-approved.

Does it work without a notch?

Yes. On a Mac without a notch, Island appears as a menu-bar item. ⌃⌥H, ⌃⌥N, the deck, details, and delivery all still work.

The droplet only lives on displays with a notch; window lock is unavailable without one. Status and the menu-bar icon still update.

Does it support Intel Macs?

Prebuilt releases are Apple Silicon builds and require macOS 14 or later. The source has not been fully validated on Intel. If you build it yourself, verify that SwiftTerm, ScreenCaptureKit, and Accessibility reads behave the same on your machine.

What does it add over using Herdr or Ghostty directly?

See every agent, blocked state, and completion at a glance. Queue or send from the notch. Attach the terminal for the current pane in the detail view. Send a window screenshot, selected text, page URL, document path, and file attachments to the main agent together.

Full Herdr workspaces, tabs, splits, and menus still belong to Herdr. Island only provides a single-pane terminal.

02 / UsageTasks, terminal, and delivery

What does a deck row show?

The agent icon and status dot, title, project, agent kind, elapsed time, the latest terminal line, progress, queued state, and worktree marker. Blocked rows show the reason and how long they have waited.

The top has four filters: Needs attention / Running / Done / All. Press / to search; labels and project names are searchable too.

Can I message a running agent?

You can queue one message. It is delivered automatically when the current turn ends, as long as the interactive terminal for that pane is not open. A queued item can be cancelled. If sending the same message fails, its body is preserved and paused; check the terminal first, then retry manually from the deck.

Blocked or unknown-state agents are refused. Handle blocked first in the terminal.

What is the "main agent"?

The default recipient of the delivery composer. The first time you open the composer, it adopts the selected agent or the first agent that can receive a message. Clicking the recipient chip later lets you switch; the new choice becomes the main agent.

  • Main agent busy: queue one message and send it when the turn ends.
  • Main agent blocked: switch to another agent, or jump to the terminal.
  • Main agent exited or its pane was reused: "The main agent exited; this delivery will start a new one."

Identity is checked against pane, workspace, and agent kind together. A matching pane ID alone is not the same agent.

How is the detail terminal related to Herdr?

It connects to the existing session over Herdr's single-pane socket protocol 22 and renders with SwiftTerm. The size is synced directly to that pane.

Closing the detail only releases the connection; it does not stop the Herdr server, shell, or agent. After a disconnect, reconnect manually — keystrokes are not replayed automatically, and input sent before the disconnect may already have run. Check the terminal before reconnecting.

Why doesn't Esc close the detail?

When the terminal has focus, Esc, arrow keys, Tab, and Ctrl+C go to the terminal program. Use ⌘W to return to the deck.

In the deck or the composer, Esc still unwinds one layer at a time: first the composer, then search, then the detail, then the panel.

What input does the terminal support?

Keyboard, input methods (including Chinese IMEs), multi-line paste, file/image paste or drag-in, mouse reporting, Shift-drag to select text, ⌘C / ⌘V, and scrollback with the wheel. Pasted images become local PNG paths; no Enter is appended, and the files remain after the detail closes.

Not yet supported: the full key-down/repeat/key-up protocol, focus reporting, OSC 52 clipboard, and in-terminal image display. Protocol 22's mouse channel has no acknowledgement, so strict cross-channel ordering of mouse and keyboard is not guaranteed.

What can window lock do?

Hold Option while dragging the droplet to lock the window under the pointer. On send, Island tries to capture one window PNG, reads selected text, page URL, and document path automatically (requires Accessibility), and combines them with the file paths you added.

Only windows on the current Space and current display are supported. Closing and reopening a window changes its windowID; minimizing or switching Spaces hides the tether and makes capture fail; DRM- or security-protected windows may capture as black. A lock only lives for the current run.

What is the difference between dragging the droplet and ⌃⌥N?

Droplet drag uses the shared delivery composer: recipient chip (main agent or new agent), model, directory, worktree, attachments, and automatic window context. The drop point decides where it appears. A normal drag creates a new agent; Option-drag locks a window.

⌃⌥N opens the 420 × 196 quick-task panel. It reuses the current pane's directory and the last model, optionally creates a worktree, and leaves existing terminals alone. It has no recipient chip and no attachments.

How do I set up sound alerts?

Settings → Sounds. "Needs attention" and "Task complete" each take a macOS system sound and preview it when selected; both are off by default. Choose "None" to silence one category independently.

What happens with Reduce Motion on?

Panels switch instantly, status dots stop pulsing, the droplet stops breathing, and the drop ripple only fades. Dragging still follows the pointer because it is not a tweened animation.

03 / Permissions & privacyWhy does it need these permissions?

Why does it need Screen Recording?

Only to capture one screenshot when you send from a locked window. It does not record continuously or capture the whole screen. Without permission, delivery degrades to text, context, and files; sending is not blocked.

After granting permission, Island may need a restart. The capture call has no separate cancel button; if a permission dialog or ScreenCaptureKit hangs, one send may wait a long time.

Why does it need Accessibility?

Only to read selected text, page URL, and document path from the locked window as delivery context. Without permission those fields are empty; text, screenshots, and files still follow their own permission state.

Reads are best-effort: if the target app does not expose an attribute, times out, or returns nothing, delivery is not blocked.

Why does it need Automation?

Only to bring Herdr's pane to the front in Ghostty. Without Ghostty it still focuses the Herdr pane; a denied permission only loses the exact jump, not the deck or delivery.

Do screenshots, code, or prompts leave this Mac?

No. Screenshots are stored locally in ~/Library/Application Support/HerdrIsland/Captures/. The prompt contains absolute paths, window metadata, automatic context, and the task. Attachments are absolute paths; files are not copied.

Island has no account, telemetry, analytics, or network requests; updates are manual downloads from GitHub Releases. The full inventory is in What it reads.

Does Island read my code or terminal contents?

It reads the agent state, latest terminal output, current directory, labels, and terminal stream that Herdr provides, to draw the deck and detail. All of it is processed locally and never uploaded.

The detail terminal connects only to the pane you selected. Closing the detail releases the connection but does not stop the agent.

Where is data stored?

Screenshots live in ~/Library/Application Support/HerdrIsland/Captures/, keeping the newest 50. Pasted images live in ~/Library/Caches/HerdrIsland/TerminalImages/ with a 0700 directory and 0600 files; images older than 7 days are cleaned up the next time the terminal opens or an image is pasted. Preferences and the main-agent identity live in UserDefaults.

Full paths, retention, and removal steps are in What it reads and Uninstall.

Are attachments copied anywhere?

No. Attachments are absolute paths, at most 8. Island checks that each file is still readable before sending; queued messages are checked again before delivery, and missing files are removed. Only absolute paths are supported; ~/ is expanded.

04 / Install & updatesDownload, allow, and update

How do I install it?

Download HerdrIsland-<version>.zip and the matching .sha256, put them in the same directory, verify, unzip, and drag HerdrIsland.app into /Applications.

shasum -a 256 -c HerdrIsland-<version>.zip.sha256
xattr -dr com.apple.quarantine /Applications/HerdrIsland.app

You can also click "Open Anyway" in System Settings → Privacy & Security. The full walkthrough is in Install.

Why does Gatekeeper block the first launch?

The app is ad-hoc signed and not notarized by Apple, so macOS does not show an identified developer. The download is not corrupt; allow it manually as described above. Do not disable Gatekeeper globally with sudo spctl --master-disable.

Why do permissions get asked again after an update?

An ad-hoc signature identity can change between builds, so macOS may treat the new version as a different app and ask again for Automation, Screen Recording, or Accessibility. Check Settings → Permissions after each update; replacing the app may preserve the grants or may prompt again.

A stable Developer ID signature and notarization would avoid this; the current build has neither.

Is there auto-update?

No. Island does not check for updates over the network or download anything in the background. New versions are published on GitHub Releases; download and replace manually.

How do I uninstall it completely?

Quit the app, delete the app, Application Support/HerdrIsland, and Caches/HerdrIsland, then remove the Automation, Screen Recording, and Accessibility grants in System Settings. Island installs no background service and registers no login item.

Step-by-step instructions are in Uninstall.

05 / TroubleshootingStale status, no connection, failed sends

Status is not updating / cannot connect to Herdr?

Check Settings → Environment first: do the executable and socket exist? Confirm Herdr 0.9.5 is running. If the socket cannot be read, Island falls back to the CLI and retries the socket after a 10-second cooldown.

Restart Island after moving Herdr or changing HERDR_SOCKET_PATH. Write operations such as create and submit are not retried automatically.

The terminal says the protocol is incompatible?

Island currently adapts only to Herdr 0.9.5's single-pane protocol 22. If upgrading or downgrading Herdr changes the protocol, the detail says so explicitly; the deck, delivery, and jumps still work, and the full terminal remains Herdr / Ghostty.

The button says "Needs attention" or the send is refused?

Common causes:

  • The agent is blocked: handle it in the terminal; Island will not answer for you.
  • The agent is busy with one message already queued: wait for the turn to end, or cancel the queued message.
  • The main agent is gone: choose another recipient, or start a new agent.
  • An attachment is not an absolute path, a file moved, or the draft is empty.

The composer's notice states the reason; "Switch" opens the recipient picker.

Why is the screenshot black or failed?

DRM- or security-protected windows may capture as black; public APIs cannot bypass that. Minimizing the window, switching Spaces, or closing and reopening it (a new windowID) also makes capture fail. On failure, delivery degrades to text, context, and files and keeps the task you typed.

Why is a workspace left behind after a failed new task?

Creating a task has three stages: prepare the directory, start the model, then submit and confirm. If a later stage fails, the workspace already created is retained and the error includes its pane ID. Island does not retry creation or resend automatically, to avoid writing twice when the outcome is unknown.

Inspect the terminal first, then decide whether to retry or start a separate task. Island does not guarantee that the task itself completes.

How do I report a problem?

Open an issue on GitHub Issues. Include the app version (Settings → Environment), macOS version, Herdr version, any protocol message, reproduction steps, and relevant logs.

Do not paste terminal output containing sensitive code, tokens, or full window screenshots. Keep only what is needed for a minimal reproduction.
