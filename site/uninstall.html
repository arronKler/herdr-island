Herdr Island/Docs/Uninstall

Removal · Local and complete

Remove it completely.

Island installs no background service, login item, or cloud account, so uninstalling is mostly deleting the app and two local directories. This page also removes the permission grants macOS keeps separately.

Uninstalling Island does not touch Herdr. Your workspaces, worktrees, agent sessions, and terminal history belong to Herdr and keep running unless you stop them there.

01 / Before you startDecide what you want to keep

Choose how far to go:

  • Delete the app only. Screenshots, pasted images, preferences, and permissions remain. Reinstalling picks them up again.
  • Delete the app and local data. Removes screenshots, pasted images, and preferences. Permissions may remain in System Settings.
  • Delete everything. Also removes the Automation, Screen Recording, and Accessibility grants. This is the full removal described below.

If you only want to reset a broken install, keep the local data and remove the app plus its permissions; see Clean reinstall.

02 / Quit and deleteThe app itself

  1. Click the Herdr Island menu-bar item and choose Quit. If the menu is unavailable, run pkill -x HerdrIsland.
  2. Open /Applications and move HerdrIsland.app to the Trash.
  3. Empty the Trash when you are ready. The app bundle is the only executable Island installs.
# Confirm the process is gone
pgrep -fl HerdrIsland || echo "not running"

# Delete the app
rm -rf /Applications/HerdrIsland.app

If defaults delete says the domain does not exist, the preference was already absent. Nothing else needs cleaning.

04 / Remove permissionsmacOS keeps these separately

Deleting an app does not always remove its privacy grants. Open System Settings → Privacy & Security and remove Herdr Island from each list where it appears:

  • Automation: Herdr Island controlling Ghostty.
  • Screen Recording: used only for one window screenshot on send.
  • Accessibility: used only to read selected text, URL, and document path from a locked window.

You can also reset the grants from Terminal. The bundle identifier is local.herdr.island:

tccutil reset AppleEvents local.herdr.island
tccutil reset ScreenCapture local.herdr.island
tccutil reset Accessibility local.herdr.island

These commands reset only Island's entries. If macOS reports that the service is unknown or nothing was reset, remove the entries manually in System Settings. Do not run tccutil reset All unless you intend to reset every app's permissions.

05 / VerifyNo process, no data, no grant

# No Island process
pgrep -fl HerdrIsland || echo "no process"

# No local data
ls ~/Library/Application\ Support/HerdrIsland 2>/dev/null || echo "no app support"
ls ~/Library/Caches/HerdrIsland 2>/dev/null || echo "no cache"

# No preference domain
defaults read local.herdr.island 2>/dev/null || echo "no preferences"

# No login item or launch agent
launchctl list | grep -i herdr || echo "no launch agent"

Then check System Settings → Privacy & Security: Automation, Screen Recording, and Accessibility should no longer list Herdr Island. Also check General → Login Items; Island never registers one, but this confirms nothing was added on your behalf.

06 / What stays behindHerdr and the agents

Island is a front end. Removing it leaves the following untouched:

  • Herdr itself and its socket, configuration, and server.
  • Workspaces, worktrees, panes, and running agent processes.
  • Agent CLIs and their own credentials, sessions, and logs.
  • The Ghostty app and anything it is currently running.
  • macOS logs that may mention the app, such as unified logging entries. These are managed by the system, not by Island.

To stop Herdr, use Herdr's own commands or quit it directly. Island does not install a daemon that would keep it alive.

07 / Clean reinstallStart from a blank slate

  1. Quit Island and delete /Applications/HerdrIsland.app.
  2. Remove the two data directories and the preference domain as above.
  3. Reset the three permission grants with the tccutil commands above.
  4. Download the latest release and .sha256, verify, unzip, and drag the app to /Applications.
  5. Open it, approve Gatekeeper, then grant Automation, Screen Recording, and Accessibility again when prompted.

The install walkthrough, including the quarantine command, is on the main page. If a permission still does not appear after reinstall, log out and back in or reboot; macOS caches privacy decisions per app identity.
