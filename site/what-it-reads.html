What it reads.

Island is a local tool: no account, telemetry, or network requests. Below is every piece of data it reads from Herdr and macOS, writes to Herdr, and keeps on this Mac. Last checked 2026-11-11 against Herdr 0.9.5 and single-pane protocol 22.

00 / In one lineRead Herdr, write Herdr, keep it local

Read

Herdr status and terminal

Agent state, latest output, current directory, labels, worktree, and the terminal stream. Optionally the locked window's selected text, URL, document path, and one screenshot.

Write

Only what you trigger

Create a workspace / worktree, start an agent, submit a prompt, focus a pane, or type into the detail terminal. No background writes.

Keep

Stays on this Mac

Screenshots, pasted images, and preferences live in local directories. Prompts, code, attachment paths, and screenshots are not uploaded; there is no account or cloud sync.

The only path off this Mac: there isn't one. Island makes no network requests. Herdr itself, the agents you use, and macOS may have their own network behavior; that is not Island reading or writing.

The socket defaults to ~/.config/herdr/herdr.sock and can be overridden with HERDR_SOCKET_PATH or HERDR_SOCKET. Settings → Environment shows the actual path.

Island does not read the microphone, camera, calendar, contacts, location, Bluetooth, focus status, or the whole disk. Accessibility reads only a few text attributes from the window you locked; Screen Recording captures one target window only when you send.

Write operations such as create and submit are not retried automatically. A blocked agent is not accepted by agent prompt, and Island does not fall back to simulated keys.

Island installs no background service, registers no login item, writes no LaunchAgent, and creates no database outside Application Support.

05 / Permission matrixAll three are on demand

PermissionPurposeWithout it
AutomationBring Herdr's pane to the front in GhosttyStill focuses the Herdr pane; the exact jump is unavailable
Screen RecordingCapture one locked window when sendingNo screenshot; everything else is unaffected
AccessibilityRead selected text, URL, and document path from the locked windowContext is empty; everything else is unaffected

Settings → Permissions shows the state and opens the matching system pane. macOS may require restarting Island after a permission change. Island has no microphone, camera, calendar, contacts, location, or Bluetooth permission.

06 / What it does not doThe explicit no-list

  • No account, cloud sync, telemetry, analytics, or crash upload.
  • No network requests; no update check and no background download.
  • No continuous recording while locked, no whole-screen capture, no reading of other windows.
  • No clipboard history and no background clipboard reads.
  • No copying attachments; the prompt contains absolute paths only.
  • No auto-approving blocked agents, no sending y / Enter, no simulated confirmation keys.
  • No uploading prompts, code, attachment paths, or screenshots anywhere.
  • No background service or login item; no Island process remains after quitting.

What you can verify: every line above maps to a place in the source. The main files and self-check commands are below. If the inventory and the actual behavior disagree, that is a bug — please report it.

07 / Verify it yourselfSource, paths, and network

Main source files

  • HerdrWire.swift: the agent fields read from Herdr.
  • HerdrCLI.swift: socket / CLI read and write commands.
  • HerdrTerminalSession.swift: the single-pane terminal protocol.
  • WindowContextService.swift: Accessibility reads.
  • WindowCaptureService.swift: ScreenCaptureKit capture and the 50-image cap.
  • TerminalPasteboard.swift: pasted-image cache, 0700 / 0600, and 7-day cleanup.
  • MainAgentStore.swift: the main agent stores identity only.
  • IslandSettings.swift: preferences and alert sounds.

Check on this Mac

# Preferences (main agent, directories, sounds, and so on)
defaults read local.herdr.island

# Screenshots and pasted images
ls -la ~/Library/Application\ Support/HerdrIsland/Captures/
ls -la ~/Library/Caches/HerdrIsland/TerminalImages/

# Signing and version
codesign -dv /Applications/HerdrIsland.app
defaults read /Applications/HerdrIsland.app/Contents/Info.plist CFBundleShortVersionString

# Network: watch with Little Snitch / nettop, or search the source for network clients
grep -rnE 'URLSession|URLRequest|NWConnection' Sources

Without a development environment, watch Activity Monitor → Network or Little Snitch: Island should make no network connections while idle or while sending.
