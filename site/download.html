01 / InstallThree steps, one approval.

  1. Download and unzip. Use the Download button above to get HerdrIsland.zip, then double-click it.
  2. Move it into Applications. Drag HerdrIsland.app into /Applications.
  3. Approve the first launch. The app is ad-hoc signed and not notarized by Apple, so Gatekeeper blocks it. Open System Settings → Privacy & Security, click Open Anyway in the Security section, then enter an administrator password.

If you use Homebrew, the project ships its own tap. It unzips the release and moves the app into /Applications, but it does not clear the quarantine flag, so the first-launch approval above still applies:

brew install --cask arronKler/tap/herdr-island

Updates stay with the app's own updater. brew uninstall --cask --zap herdr-island removes the app and its saved state.

Alternatively, run both commands on a freshly extracted copy before its first launch, then move it into /Applications:

chmod -R u+w ~/Downloads/HerdrIsland.app/Contents/Resources
xattr -dr com.apple.quarantine ~/Downloads/HerdrIsland.app

The first command also repairs the read-only resource in v0.2.1. Use the downloaded copy; App Management may prevent changes to an installed app. If opening the app does nothing, follow the fresh-copy recovery steps.

Automatic updates do not repeat this step. A manually downloaded version may, so do not disable Gatekeeper globally with sudo spctl --master-disable. After launch, grant Screen Recording, Automation, and Accessibility permissions when asked; the full walkthrough is in the install section.

02 / UpdatesAfter install, updates finish themselves.

Island checks GitHub once a day, downloads updates in the background, and installs them when you quit or restart. The feed and every archive are EdDSA-signed; the app verifies them against its built-in public key before installing.

Replacing an older version by hand may require approving the first launch again; automatic updates do not. You can also check for updates manually from the app at any time.

03 / RequirementsWhat you need.

System
macOS 14 Sonoma or later.
Herdr
Herdr 0.9.5+, discovered at ~/.local/bin/herdr by default. Island does not bundle Herdr.
Ghostty
Optional. Exact jumps need it; without it, Island still focuses the Herdr pane.
Permissions
Screen Recording for window screenshots, Automation for Ghostty jumps, Accessibility optional. None are needed for basic status.

04 / VerificationVerification is automatic.

No manual check is required. Updates are signature-verified; the .sha256 in the release is only there if you want to confirm a download is not corrupt.

Check the download by hand

Download HerdrIsland.zip.sha256, put it in the same folder as the zip, then run:

shasum -a 256 -c HerdrIsland.zip.sha256

OK means the file is intact. This only proves the download is not corrupt; it does not replace the first-launch approval.
