01 / 基础它是什么，和 Herdr 什么关系？

Herdr Island 是什么？和 Herdr 是什么关系？

Island 是 Herdr 的 macOS 图形前端。Herdr 仍然是执行者：创建 workspace、启动 agent、提交消息、运行终端。Island 把状态、任务台、终端和派发放在刘海旁边，不替代 Herdr，也不自己接 Claude Code / Codex。

这意味着 Island 能覆盖多少 agent，取决于 Herdr 识别和启动了多少 agent。

一定要先装 Herdr 吗？

是。需要 Herdr 0.9.5；详情里的交互终端适配单 pane 协议 22。默认二进制路径是 ~/.local/bin/herdr，socket 是 ~/.config/herdr/herdr.sock；也可以用 HERDR_SOCKET_PATH 或 HERDR_SOCKET 覆盖。

设置 → 运行环境里能看到 Island 实际发现的可执行文件和 socket。移动 Herdr 后重启 Island 即可刷新。

支持哪些 agent？

Herdr 识别到的 agent 都会出现在任务台。新建任务时可选 Claude、Codex、Cursor、Pi、Gemini、Copilot、OpenCode、Cline、Amp、Grok、Qwen、Kimi 共 12 种。

不同 agent 的首条任务和 blocked 弹窗处理方式不同：Claude、Cursor 的单行首条任务可以作为启动参数原生传入；Codex 和多行任务会先确认真实空输入框；Cursor 的工作区信任弹窗、Codex 的用量/模型选择弹窗必须由你亲自处理。

Island 会自动批准 blocked 吗？

不会。Island 不代发 y、Enter 或任何确认键；自动消息投递走的是会拒绝 blocked agent 的 herdr agent prompt。

你可以在详情的交互终端里阅读、选择并回答，也可以点「在 Herdr 打开」回到 Herdr 处理。设置页也把这条写成固定的安全说明：blocked 不会被自动批准。

没有刘海能用吗？

能。没有刘海时岛以菜单栏形态出现，⌃⌥H 和 ⌃⌥N、任务台、详情和投递照常可用。

水滴只在有刘海的屏幕上常驻；没有刘海时窗口锁定暂不可用。状态和菜单栏图标仍然会更新。

支持 Intel Mac 吗？

预编译版本为 Apple Silicon 构建，要求 macOS 14 或更新版本。源码没有针对 Intel 做完整验证；如果你自己构建，需要确认 SwiftTerm、ScreenCaptureKit 和辅助功能读取在你的机器上行为一致。

和直接开 Herdr / Ghostty 比，Island 多什么？

一眼看到所有 agent、blocked 和完成；在刘海下排队或发送；详情里直接接当前 pane 的终端；把窗口截图、选中文本、网页地址、文档路径和附件一起投递给主 agent。

Herdr 的完整工作区、标签、分屏和菜单仍然用 Herdr；Island 只做单 pane 终端。

02 / 使用任务、终端和投递

任务台的行显示什么？

agent 图标和状态点、标题、项目、agent 类型、运行时长、最近一行终端输出、进度、排队状态和 worktree 标记。blocked 行会显示原因和等待时长。

顶部有「待处理 / 运行中 / 已完成 / 全部」四个筛选；按 / 进入搜索，标签和项目名也参与搜索。

运行中的 agent 可以发消息吗？

可以排队一条。本轮结束且没有打开该 pane 的交互终端时自动投递；排队项可以取消。同一条消息发送失败后，正文会保留并暂停，先去终端检查，再回任务台手动重试。

blocked 或状态未知的 agent 会被拒绝。blocked 需要先在终端处理。

「主 agent」是什么？

投递框默认的收件人。第一次打开投递框时会采用当前选中或第一个可接收消息的 agent；之后点收件人 chip 可以切换，选中的会成为新的主 agent。

  • 主 agent 忙：可以排队一条，等本轮结束自动发送。
  • 主 agent blocked：提示换一个，或跳去终端处理。
  • 主 agent 退出或 pane 被复用：提示「主 Agent 已退出，这次将新建」。

身份按 pane、workspace 和 agent kind 一起判断；只有 pane ID 相同不算同一个 agent。

详情终端和 Herdr 是什么关系？

通过 Herdr 的单 pane socket 协议 22 连接现有会话，SwiftTerm 渲染。尺寸直接同步给该 pane。

关闭详情只释放连接，不停止 Herdr server、shell 或 agent。断线后手动重连，已输入的按键不会自动重发；断开前已经发出的输入可能已经执行，重连前先检查终端。

为什么终端里 Esc 不退出详情？

详情聚焦终端时，Esc、方向键、Tab 和 Ctrl+C 都交给终端程序。用 ⌘W 返回任务台。

在任务台或输入框里，Esc 仍然是逐层退出：先收输入框，再退出搜索、详情，最后收起面板。

终端支持哪些输入和操作？

键盘、中文输入法、多行粘贴、文件/图片粘贴或拖入、鼠标报告、Shift + 拖动选择文字、⌘C / ⌘V、滚轮历史。图片会转成本地 PNG 路径，不追加 Enter，关闭详情后仍保留。

还不支持：完整的按键按下/重复/释放协议、焦点报告、OSC 52 剪贴板、终端内图像显示。协议 22 的鼠标通道没有处理确认，鼠标与键盘跨通道的严格排序不保证。

窗口锁定能做什么？

按住 Option 拖动水滴，锁定指针下的窗口。发送时尝试截一张窗口 PNG，并自动读取选中文本、网页地址、文档路径（需要辅助功能），再加上你添加的文件路径，一起拼进投递。

只支持当前 Space、当前屏幕上的窗口；窗口关闭再打开会换 windowID；最小化或切到别的 Space 时连线隐藏、截图会失败；受 DRM 或安全保护的窗口可能只能截到黑屏。锁定只存在于本次运行期间。

水滴拖拽和 ⌃⌥N 有什么区别？

水滴拖拽使用共享投递框：收件人 chip（主 agent 或新建）、模型、目录、worktree、附件、自动窗口上下文；落点决定位置。普通拖动创建新 agent；按住 Option 拖动是锁定窗口。

⌃⌥N是 420 × 196 的快速新任务框，沿用当前 pane 的目录和上次模型，可选 worktree，不改动现有终端。它不提供收件人 chip 和附件。

怎么设置声音提醒？

设置 → 声音。「需要你处理」和「任务完成」可以分别选 macOS 内置提示音，选中即试听；默认关闭。选择「无」可以单独关闭某一类提醒。

开了 Reduce Motion 会怎样？

面板改为瞬时切换，状态点不再脉冲，水滴停止呼吸，落点涟漪只淡出。拖拽本身仍然跟随指针，因为它不是补间动画。

03 / 权限与隐私它为什么要这些权限？

为什么需要屏幕录制？

只用于窗口锁定后的发送时截图。不会持续录屏，也不会截整个屏幕。未授权时投递降级为文字、上下文和文件，不阻断发送。

授权后可能需要重启 Island。截图调用没有单独的取消按钮；权限弹窗或 ScreenCaptureKit 卡住时，一次发送可能等待较久。

为什么需要辅助功能？

只用于读取锁定窗口的选中文本、网页地址和文档路径，作为投递上下文。未授权时这些字段为空；文字、截图和文件仍按其他授权情况发送。

读取是 best-effort：目标 App 不暴露属性、超时或返回空时，不会阻塞投递。

为什么需要自动化？

只用于把 Herdr 的 pane 带到 Ghostty 前台。没有 Ghostty 时仍然会聚焦 Herdr pane；权限被拒只影响精确跳转，不影响任务台和投递。

截图、代码和 prompt 会离开本机吗？

不会。截图保存在本机 ~/Library/Application Support/HerdrIsland/Captures/，prompt 里只有绝对路径、窗口元数据、自动上下文和任务。附件只传绝对路径，不复制文件。

Island 没有账号、遥测、分析或网络请求；更新通过 GitHub Releases 手动下载。完整清单见它读了什么。

Island 会读我的代码或终端内容吗？

会读 Herdr 提供的 agent 状态、最近终端输出、当前目录、标签和终端流，用于任务台和详情显示；这些都只在本机处理，不上传。

详情终端只连接你选中的 pane；关闭详情只释放连接，不停止 agent。

数据存在哪里？

截图在 ~/Library/Application Support/HerdrIsland/Captures/，保留最新 50 张；粘贴图片在 ~/Library/Caches/HerdrIsland/TerminalImages/，目录 0700、文件 0600，超过 7 天的会在下次打开终端或粘贴图片时清理；偏好和主 agent 身份在 UserDefaults。

完整路径、保留策略和删除方式见它读了什么与卸载。

附件会复制到别处吗？

不会。附件只传绝对路径，最多 8 个。发送前会检查文件仍然可读；排队消息投递前会再次检查，缺失的文件会被移除。只支持绝对路径，~/ 会展开。

04 / 安装与升级下载、放行和更新

怎么安装？

下载 HerdrIsland-<版本>.zip 和同名 .sha256，放在同一目录校验后解压，把 HerdrIsland.app 拖进 /Applications。

shasum -a 256 -c HerdrIsland-<版本>.zip.sha256
xattr -dr com.apple.quarantine /Applications/HerdrIsland.app

也可以在系统设置 → 隐私与安全性里点「仍要打开」。具体步骤见安装。

为什么首次打开被 Gatekeeper 拦截？

应用只有 ad-hoc 签名，没有经过 Apple 公证，所以系统不会显示「已识别的开发者」。这不是下载损坏；按安装步骤手动放行即可。不要用 sudo spctl --master-disable 全局关闭 Gatekeeper。

更新后为什么要重新授权？

ad-hoc 签名的身份可能随构建变化，macOS 会把新版本当成不同 app，重新询问自动化、屏幕录制或辅助功能。每次更新后检查设置 → 权限；如果只是替换了 app，权限可能仍然保留，也可能再次询问。

用稳定的 Developer ID 签名和公证可以避免这个问题；当前版本还没有公证。

有自动更新吗？

没有。Island 不主动联网检查更新，也不会在后台下载。新版本发布在 GitHub Releases，需要手动下载替换。

怎么完全卸载？

退出 app，删除 app、Application Support/HerdrIsland 和 Caches/HerdrIsland，再到系统设置移除自动化、屏幕录制和辅助功能授权。Island 不安装后台服务，也不注册登录项。

逐项步骤见卸载。

05 / 故障排查状态不动、连不上、发不出去

状态不更新 / 连接不上 Herdr？

先看设置 → 运行环境：可执行文件和 socket 是否存在。确认 Herdr 0.9.5 正在运行；socket 读不到时 Island 会回退 CLI，冷却 10 秒后再试 socket。

移动过 Herdr 或改过 HERDR_SOCKET_PATH 后重启 Island。创建和提交等写操作不会自动重试。

终端提示协议不兼容？

当前只适配 Herdr 0.9.5 的单 pane 协议 22。升级或降级 Herdr 后如果协议变了，详情会明确提示不兼容；任务台、投递和跳转仍然可用，完整终端请用 Herdr / Ghostty。

按钮是「需处理」或发送被拒绝？

常见原因：

  • agent blocked：去终端处理，岛不会代答。
  • agent 忙且已有一条排队：等本轮结束，或取消排队。
  • 主 agent 不在了：换一个收件人，或新建 agent。
  • 附件不是绝对路径、文件已被移动，或草稿为空。

投递框的 notice 会说明原因；「换一个」会打开收件人选择。

为什么截图是黑屏或失败？

受 DRM 或安全保护的窗口可能只能截到黑屏，公开 API 无法绕过。窗口最小化、切到别的 Space、关闭后重新打开（windowID 变化）也会让截图失败。失败时投递会降级为文字、上下文和文件，不会丢掉已输入的任务。

新任务失败后为什么留下了一个 workspace？

创建任务分「准备目录、启动模型、提交并确认」三步。失败时已经创建的 workspace 会保留，错误里带 pane ID；Island 不会自动重试创建，也不会重复发送，以免在结果不确定时写入两次。

先在终端检查，再决定重试或「另建任务」。任务本身是否完成不由 Island 保证。

怎么反馈问题？

到 GitHub Issues。带上 app 版本（设置 → 运行环境）、macOS、Herdr 版本、协议提示、复现步骤和相关日志。

不要贴包含敏感代码、token 或完整窗口截图的终端输出；只保留最小复现所需的部分。
