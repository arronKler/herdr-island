Herdr Island/文档/卸载

移除 · 本机且完整

把它删干净。

Island 不安装后台服务、登录项，也没有云端账号，所以卸载主要是删除应用和两个本地目录。这份步骤也会清掉 macOS 另外保存的权限授权。

卸载 Island 不会动 Herdr。你的 workspace、worktree、agent 会话和终端历史都属于 Herdr；除非你在 Herdr 里停止它们，否则它们会继续运行。

01 / 先决定保留什么清理到哪一步

按需要选择：

  • 只删应用。截图、粘贴图片、偏好和权限都会保留；重新安装后会接着使用。
  • 删应用和本地数据。移除截图、粘贴图片和偏好；系统设置里的权限可能仍然保留。
  • 全部删除。再移除自动化、屏幕录制和辅助功能授权。这就是下面这份完整流程。

如果只是想修复一次损坏的安装，保留本地数据，只删应用和权限即可；见干净重装。

02 / 退出并删除应用应用本体

  1. 点菜单栏里的 Herdr Island，选择退出。菜单不可用时运行 pkill -x HerdrIsland。
  2. 打开 /Applications，把 HerdrIsland.app 移到废纸篓。
  3. 确认后清空废纸篓。应用包是 Island 安装的唯一可执行文件。
# 确认进程已经退出
pgrep -fl HerdrIsland || echo "not running"

# 删除应用
rm -rf /Applications/HerdrIsland.app

03 / 删除本地数据截图、图片、偏好、更新

Island 只写这几个位置。先删应用不影响它们，删除它们也不影响其他 app。

如果 defaults delete 提示 domain 不存在，说明偏好已经不在了，不需要再清理。

04 / 移除权限macOS 会单独保存

删除应用不一定删除隐私授权。打开系统设置 → 隐私与安全性，在每个出现 Herdr Island 的列表里移除它：

  • 自动化：允许 Herdr Island 控制 Ghostty。
  • 屏幕录制：只用于发送时截一张窗口图。
  • 辅助功能：只用于读取锁定窗口的选中文本、URL 和文档路径。

也可以在终端重置授权。Bundle ID 是 local.herdr.island：

tccutil reset AppleEvents local.herdr.island
tccutil reset ScreenCapture local.herdr.island
tccutil reset Accessibility local.herdr.island

这些命令只重置 Island 的条目。如果 macOS 提示服务未知或没有重置任何内容，就在系统设置里手动移除。除非你确实想重置所有 app 的权限，不要运行 tccutil reset All。

05 / 核对没有进程、数据或授权

# 没有 Island 进程
pgrep -fl HerdrIsland || echo "no process"

# 没有本地数据
ls ~/Library/Application\ Support/HerdrIsland 2>/dev/null || echo "no app support"
ls ~/Library/Caches/HerdrIsland 2>/dev/null || echo "no cache"
ls ~/Library/Caches/local.herdr.island 2>/dev/null || echo "no update cache"

# 没有偏好域
defaults read local.herdr.island 2>/dev/null || echo "no preferences"

# 没有登录项或 LaunchAgent
launchctl list | grep -i herdr || echo "no launch agent"

再看系统设置 → 隐私与安全性：自动化、屏幕录制和辅助功能里不应再出现 Herdr Island。顺便检查通用 → 登录项；Island 从不注册登录项，这一步只是确认没有别的东西替它添加。

06 / 还会留下什么Herdr 和 agent

Island 只是一个前端。删除它不会动这些：

  • Herdr 本体，以及它的 socket、配置和 server。
  • Workspace、worktree、pane 和正在运行的 agent 进程。
  • Agent CLI 自己的凭据、会话和日志。
  • Ghostty 应用，以及它正在运行的内容。
  • macOS 统一日志里可能提到本应用的条目。它们由系统管理，不属于 Island 的本地数据。

要停止 Herdr，用 Herdr 自己的命令或直接退出它。Island 没有安装任何让 Herdr 保持运行的守护进程。

07 / 干净重装从空白状态开始

  1. 退出 Island，删除 /Applications/HerdrIsland.app。
  2. 按上面的步骤删除数据目录和偏好域。
  3. 用上面的 tccutil 命令重置三项授权。
  4. 下载最新版本，解压，把应用拖进 /Applications。
  5. 打开应用，放行 Gatekeeper，再按提示授予自动化、屏幕录制和辅助功能。

包含 quarantine 命令的安装步骤在主页。如果重装后权限仍然不出现，注销再登录或重启；macOS 会按 app 身份缓存隐私决定。
