它读了什么。

Island 是本地工具：没有账号或遥测，唯一的网络请求是从 GitHub 检查更新和下载更新。下面是它从 Herdr 和 macOS 读取、向 Herdr 写入、在本机保留的全部数据。最近核对：2026-11-12，对应 Herdr 0.9.5 与单 pane 协议 22。

00 / 一句话读 Herdr，写 Herdr，留本机

读

Herdr 的状态和终端

agent 状态、最近输出、当前目录、标签、worktree 和终端流。可选读取锁定窗口的选中文本、URL、文档路径和一张截图。

写

你明确触发的操作

创建 workspace / worktree、启动 agent、提交 prompt、聚焦 pane、向详情终端输入。没有后台写入。

留

只留在本机

截图、粘贴图片和偏好保存在本机目录；prompt、代码、附件路径和截图不上传，也没有账号或云同步。

唯一离开本机的路径：更新检查。Sparkle 每天通过 HTTPS 从 GitHub 请求签名的 appcast.xml，有新版本时下载归档。不发送账号、标识、prompt 或使用数据。Herdr 本身、你使用的 agent 和 macOS 系统可能有自己的网络行为，那些不属于 Island 的读取或写入。

01 / 从 Herdr 读状态、预览和终端

数据来源用途离开本机
agent 列表与元数据
pane / workspace / tab、agent kind、状态、标题、cwd / foreground_cwd、completion_seq、state_change_seq、state_labels、name、focused、revision		 Unix socket 的 agent.list 和 pane.list；每 1.5 秒采样，状态事件即时更新 任务台、状态、筛选、搜索、主 agent 解析 否
最近终端输出
recent unwrapped 预览		 socket 的 agent.read；断线时回退 herdr agent read --source recent-unwrapped 运行中行尾的最近一行、详情预览 否
终端流与尺寸
连续 ANSI 帧、主屏历史、鼠标模式、PTY 尺寸		 单 pane 二进制 socket，协议 22；TerminalAttach / pane.get 详情里的交互终端 否
状态事件
pane_agent_status_changed / pane.agent_status_changed		 Herdr socket 事件 不等待下一次采样，立即更新状态 否
CLI 回退结果
herdr agent list、agent read、pane list 等		 本地可执行文件 ~/.local/bin/herdr 或 PATH 中的 herdr socket 不兼容或断线时的只读回退；写操作不走自动重试 否

socket 路径默认 ~/.config/herdr/herdr.sock，可用 HERDR_SOCKET_PATH 或 HERDR_SOCKET 覆盖。设置 → 运行环境显示实际路径。

02 / 从 macOS 读只在对应动作发生时

数据何时权限不授权时
选中文本、网页地址、文档路径
上限 4,000 / 2,048 / 1,024 字符		 锁定窗口后组稿和发送时，对目标 App 做 best-effort 读取 辅助功能 字段为空；其他内容照常发送
窗口截图
一张目标窗口 PNG		 只在你按下发送时；不持续录屏，不截整个屏幕 屏幕录制 不附截图；文字、上下文和文件照常发送
Ghostty 终端定位
通过 Apple Events 查到承载 Herdr 的 tty		 你点「去终端」或详情里的跳转时 自动化 仍然聚焦 Herdr pane，只是不精确到 Ghostty 终端
剪贴板
文字、文件 URL、PNG / TIFF 图片		 你在详情里按 ⌘V、从菜单粘贴，或拖入文件时 无额外权限 不粘贴；没有后台剪贴板历史
你选择的文件
绝对路径		 你添加附件或拖入投递框时 无额外权限 不添加附件

Island 不读取麦克风、摄像头、日历、通讯录、位置、蓝牙、焦点状态或整个磁盘。辅助功能只读取你锁定的那个窗口的少量文本属性；屏幕录制只在你发送时截一张目标窗口。

03 / 写到 Herdr只在你明确操作时

操作对应的 Herdr 能力触发
创建工作区workspace create --cwd … --label … --no-focus新任务 / 投递到新 agent
创建隔离 worktreeworktree create --cwd … --branch … --label … --no-focus投递框打开 worktree
启动 agentagent start新任务 / 投递到新 agent
提交 promptagent prompt（必要时 --wait）发送或排队消息成交
聚焦 pane / workspaceagent focus、workspace focus点「去终端」/「在 Herdr 打开」
终端输入单 pane socket：按键、文字、粘贴、滚动、尺寸、鼠标报告你在详情终端里实际输入或操作
等待状态agent wait确认新任务或发送后的状态

创建和提交等写操作没有自动重试。blocked 的 agent 不会被 agent prompt 接受，Island 也不会改用按键绕过。

04 / 写到本机目录、保留和删除

位置内容保留删除方式
~/Library/Application Support/HerdrIsland/Captures/ 窗口截图 PNG 保留最新 50 张，写入新截图时清理旧图 删除目录；或卸载时清理
~/Library/Caches/HerdrIsland/TerminalImages/ ⌘V / 拖入的图片转成的 PNG 目录 0700、文件 0600；超过 7 天在下次打开终端或粘贴时清理 删除目录；或卸载时清理
~/Library/Caches/local.herdr.island/ 更新待安装时 Sparkle 下载的更新包，以及 appcast 请求缓存 更新安装后清理；Sparkle 会删除旧下载 删除目录；或卸载时清理
UserDefaults local.herdr.island 主 agent 身份（pane / kind / name / project / workspace）、上次模型、上次 / 默认目录、自动展开开关、完成停留、两类提示音、Sparkle 更新状态（最近检查时间、更新分组标识） 直到删除偏好 defaults delete local.herdr.island
系统剪贴板 你点「复制命令」或从终端复制的内容 由 macOS 和你的其他 app 管理 正常覆盖或清空剪贴板

Island 不安装后台服务、不注册登录项、不写 LaunchAgent，也不在 Application Support 之外创建数据库。

05 / 权限对照三项都是按需

权限用途不授权时
自动化把 Herdr 的 pane 带到 Ghostty 前台仍然聚焦 Herdr pane；精确跳转不可用
屏幕录制发送时截一张锁定窗口不附截图；其他内容照常
辅助功能读取锁定窗口的选中文本、URL、文档路径上下文为空；其他内容照常

在设置 → 权限里可以查看状态并打开对应的系统设置。更改权限后 macOS 可能要求重启 Island。没有麦克风、摄像头、日历、通讯录、位置或蓝牙权限。

06 / 不做什么明确的不做清单

  • 没有账号、云同步、遥测、分析或崩溃上传。
  • 除每日从 GitHub 检查签名 appcast 和下载更新外，不发起网络请求。
  • 不在锁定期间持续录屏，不截整个屏幕，不读其他窗口。
  • 没有剪贴板历史，不在后台读取剪贴板。
  • 不复制附件；prompt 里只有绝对路径。
  • 不自动批准 blocked，不代发 y / Enter，不模拟确认按键。
  • 不把 prompt、代码、附件路径或截图上传到任何地方。
  • 不安装后台服务或登录项；退出 app 后没有 Island 进程。

能验证的部分：上面每一条都能在源码里找到对应位置。下面给了主要文件和自查命令；如果你发现清单和实际行为不一致，它是 bug，请提 Issue。

07 / 自己核对源码、路径和网络

主要源码

  • HerdrWire.swift：从 Herdr 读取的 agent 字段。
  • HerdrCLI.swift：socket / CLI 读取与写入命令。
  • HerdrTerminalSession.swift：单 pane 终端协议。
  • WindowContextService.swift：辅助功能读取。
  • WindowCaptureService.swift：ScreenCaptureKit 截图和 50 张保留。
  • TerminalPasteboard.swift：粘贴图片缓存、0700 / 0600 和 7 天清理。
  • MainAgentStore.swift：主 agent 身份只存标识。
  • IslandSettings.swift：偏好和提示音。
  • UpdateController.swift：Sparkle 自动更新，唯一的网络入口。

在本机核对

# 偏好（主 agent、目录、声音等）
defaults read local.herdr.island

# 截图和粘贴图片
ls -la ~/Library/Application\ Support/HerdrIsland/Captures/
ls -la ~/Library/Caches/HerdrIsland/TerminalImages/

# 签名和版本
codesign -dv /Applications/HerdrIsland.app
defaults read /Applications/HerdrIsland.app/Contents/Info.plist CFBundleShortVersionString

# 网络：唯一的客户端是 Sparkle 更新器，用 Little Snitch / nettop 观察
grep -rn 'Sparkle' Package.swift Sources/IslandApp/UpdateController.swift

如果你没有开发环境，也可以用 macOS 的「活动监视器 → 网络」或 Little Snitch 观察：每日更新检查前后会连到 github.com，只有下载新版本时才会传输归档。Island 在空闲和发送时不产生其他网络连接。
