01 / 安装三步装好，首次打开放行一次。

  1. 下载并解压。点上面的「下载 macOS 版」得到 HerdrIsland.zip，双击解压。
  2. 放进应用程序。把 HerdrIsland.app 拖进 /Applications。
  3. 放行首次启动。应用只有 ad-hoc 签名，没有经过 Apple 公证，Gatekeeper 会拦截。到 系统设置 → 隐私与安全性，在「安全性」一栏点「仍要打开」，再输入管理员密码。

也可以在新解压副本首次打开前执行以下两条命令，再把它移动到 /Applications：

chmod -R u+w ~/Downloads/HerdrIsland.app/Contents/Resources
xattr -dr com.apple.quarantine ~/Downloads/HerdrIsland.app

第一条命令也能修复 v0.2.1 的只读资源。请对下载副本操作；已安装的应用可能受应用管理保护。双击完全没反应时，请按新副本恢复步骤处理。

自动更新不会重复这一步。手动下载的新版本可能需要，所以不要用 sudo spctl --master-disable 全局关闭 Gatekeeper。启动后按提示授予 Screen Recording、Automation 和辅助功能权限；完整说明见首页的安装一节。

02 / 更新装好之后，更新自己完成。

Island 每天从 GitHub 检查一次更新，在后台下载，并在你退出或重启时安装。更新源和每个更新包都用 EdDSA 签名，应用用内置公钥验证后才会安装。

从旧版本手动下载替换时，首次打开可能再次要求放行；自动更新不需要。在应用内也可以随时手动检查更新。

03 / 运行环境需要什么。

系统
macOS 14 Sonoma 或更新版本。
Herdr
Herdr 0.9.5+，默认从 ~/.local/bin/herdr 发现；Island 不内置 Herdr。
Ghostty
可选。精确跳转需要它；没有时仍会聚焦 Herdr pane。
权限
Screen Recording 用于窗口截图，Automation 用于跳转 Ghostty，辅助功能可选。都不影响基础状态显示。

04 / 校验校验是自动的。

不需要手动校验。自动更新由签名验证；Release 里的 .sha256 只在你想确认下载没有损坏时使用。

手动核对下载文件

下载 HerdrIsland.zip.sha256，和 zip 放在同一个目录，然后运行：

shasum -a 256 -c HerdrIsland.zip.sha256

输出 OK 表示文件完整。校验只说明下载没有损坏，不替代首次启动的系统放行。
